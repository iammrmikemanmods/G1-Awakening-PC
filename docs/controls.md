# Controls

| Context | Controls |
|---|---|
| Menus | Arrows/WASD or Tab/Shift+Tab; Enter/Space selects; Escape returns |
| Camera | WASD/arrows or mouse drag |
| Tile cursor | IJKL or Shift+arrows; Enter selects |
| Turns and units | Space ends turn; Tab selects the next unit |
| Available actions | F attack, M move, T transform, U upgrade, Z undo, R repair, C capture |
| Other unit actions | V activate unit, B tape, H tech specs |
| Texture mode | F8 switches Classic/Enhanced |
| Settings | Up/Down or Tab changes focus; Left/Right adjusts; Escape returns |
| Opening cinematic | Escape, Enter, Space or left click skips; initialization continues |

Actions remain available only in their original eligible game contexts. Help > Controls contains the in-game reference. The original-layout compatibility profile is separate from Classic/Enhanced texture selection.
